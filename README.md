> A complete SQL practice task building a **Bookstore Database** with tables, constraints, relationships, data insertion, updates, and queries.

---

### 📌 Project Overview
This is a **standalone practice task** (not part of any series).  
It covers end-to-end SQL operations for a bookstore system — from creating the database to inserting, updating, and querying data.

---

### 🗂️ Database Structure

| Table         | Description                          |
|---------------|--------------------------------------|
| `customers`   | Customer personal information        |
| `books`       | Book details, price & stock          |
| `orders`      | Customer orders and status           |
| `order_items` | Books ordered in each order          |

---

### ✨ Operations Performed

**DDL**
- `CREATE DATABASE` & `CREATE TABLE`
- `PRIMARY KEY` & `FOREIGN KEY`
- `ALTER TABLE` (ADD column, MODIFY, RENAME column)
- `NOT NULL`, `UNIQUE`, `CHECK` constraints
- `DEFAULT` values

**DML**
- `INSERT` (single & multiple rows)
- `UPDATE` (price increase, status change, city update)
- `DELETE`
- `SELECT`

---

### 🛠️ Skills Demonstrated
- Database & table creation
- Primary Key / Foreign Key relationships
- Data integrity constraints (`CHECK`, `UNIQUE`, `NOT NULL`)
- Column modification & renaming
- Default values
- Inserting, updating, and deleting records
- Basic data retrieval
